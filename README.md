# Security-focused software developer

This account publishes security tooling and software written with a security-first approach. Work includes reconnaissance and network scanning, plus secure development for Windows and Android/React Native, with an emphasis on tested, carefully scoped tools.

All security tooling is for authorized testing and education only.

## Focus areas

- Network reconnaissance and enumeration
- Secure application development
- System hardening and disk/process hygiene tooling
- Automation with Bash
